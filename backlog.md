# Backlog

## Clarify the recalibration target before recording begins

When recalibrating a saved profile, the small, muted, all-caps label is hard to notice, and the three-second countdown may end before the user knows which profile is being recalibrated. Explore a clearer heading that names the profile, and whether recalibration (or all calibration) should use a five-second countdown. Keep Cancel so the user can safely exit if the wrong profile was selected.


# Mezzo Design Principles

## Every Element Has Meaning

Visual elements should never exist purely for decoration.

Every shape, color, animation, and interaction communicates information.

---

## Motion Before Color

Motion is the primary communication tool.

Color reinforces meaning but should rarely be the first signal.

---

## Accumulation, Not Replacement

States should evolve naturally.

Each state builds upon the previous one rather than introducing an entirely different visual language.

---

## Quiet Confidence

Interfaces should feel restrained, deliberate, and premium.

Avoid unnecessary visual effects.

---

## Respect User Context

Mezzo should adapt to the user's workflow.

Launching Mezzo should never interrupt meetings or rearrange the user's workspace unnecessarily.

---

## Simplicity Requires Discipline

Removing unnecessary visual elements is considered progress.

Complexity must justify itself.

# Ambient Software

## Definition

Ambient software provides continuous awareness without demanding continuous attention.

Unlike dashboards or notifications, ambient software exists primarily in the user's peripheral vision.

---

# Characteristics

- Calm
- Persistent
- Trustworthy
- Predictable
- Quiet
- Context-aware

---

# Mezzo's Interpretation

Mezzo behaves more like an instrument than an application.

The user should think about their meeting—not Mezzo.

Mezzo simply reflects changes in speaking behavior.

---

# Interaction Model

Traditional software follows:

User → Interface

Ambient software follows:

User → Task

↓

Interface quietly reflects information

The interface becomes a companion rather than the destination.

---

# Success

The highest compliment for Mezzo is:

"I forgot it was there until I needed it."
